# What is this?
A short one-scene animation I made for fun in Godot Engine 4.7.1

All sprites were drawn in GIMP by me, that's why they don't look very well

It utilizes my [RigEye2D](https://github.com/wolfish/rig-eye-2d) plugin for eye animation as use case example
